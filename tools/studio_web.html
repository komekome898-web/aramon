モンスター作成スタジオ

iPhoneだけで 撮影 → 背景透過 → 登録 → 本番反映 まで完結します

1GitHub設定 未接続

トークンはこの端末のSafariにだけ保存され、送信先は api.github.com のみです。 作り方: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → リポジトリを aramon だけに絞り、Contents を Read and write に。

2歩行モーション

動画を選んで「プレビュー」を押すと8コマを作ります。赤枠のコマは問題ありです。
できあがった8コマはそのまま保持されます。正面・後ろの両方をプレビューしてから登録してください。

3静止画

透過していない写真でもかまいません。上で選んだ「背景の抜き方」を使って抜いてから、 正方形・被写体が高さの9割・足元が下端付近に整えます。色相も自動で取得します。

6登録して本番へ反映

「差分を確認する」を押すと、送信されるファイルと data.js / ui.js への追記内容が出ます。
コミットすると数分後に本番へ反映されます(GitHub Actions の Pages デプロイ)。 sw.js のキャッシュ番号も自動で1つ上がります。
