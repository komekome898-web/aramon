モンスター作成スタジオ

iPhoneだけで 撮影 → 背景透過 → 登録 → 本番反映 まで完結します

1GitHub設定 未接続

トークンはこの端末のSafariにだけ保存され、送信先は api.github.com のみです。 作り方: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → リポジトリを aramon だけに絞り、Contents を Read and write に。

2登録の種類

接続すると、モンスターの素体とSSRスキンが一覧に出ます。
接続すると、元にできるSSRスキンが一覧に出ます。
元スキンのアイコン・試合用・歩行16コマをリポジトリから取ってきて、同じ加工をまとめて掛けます。 絵を描き直す必要はありません。上の設定を変えて「合成して確認する」を押し直すと作り直します。
下の「歩行モーション」と「静止画」で、覚醒後の絵を用意してください。 新しいSSRスキンを足すときとまったく同じ手順です。動画からでも、画像からでも作れます (画像が1枚だけのときは、パーツ判別で歩行16コマを自動生成します)。
画像名はスキンidから決まります(mymon_ssr → アイコン mymon_ssr.png / 試合用 mymon_player_ssr.png / 歩行 mymon_ssr_walk_f1..8)。 SSRだけの特典はtier3の技名と威力です。素体の技・特性・適性は変わりません。 歩行コマは1素体に何体ぶんでも持てます。正面・後ろの両方をプレビューしていれば このスキン専用の歩行として登録します(用意しなければ静止画のままになります)。

3歩行モーション

正面向きの動画は半周期の絵が似ているため、周期を半分で拾って片足しか上がらないことがあります。 そのときは「周期の2倍」にしてプレビューし直してください。変えたらプレビューし直しが要ります。
「調べる」を押すと、絵から脚・腕・しっぽなどの候補を探します。
2枚以上ならその絵を順にコマとして並べます(8コマに足りなければ繰り返し、多ければ等間隔に選びます)。 1枚だけなら上の設定で動かします。後ろの画像を省くと正面の絵とパーツ指定をそのまま使います。 透過済みの画像はそのまま使い、そうでなければ下の抜き方で抜きます。
素材を選んで「プレビュー」を押すと8コマを作ります。赤枠のコマは問題ありです。

4静止画

透過していない写真でもかまいません。上で選んだ抜き方で背景を抜いてから、 正方形・被写体が高さの9割・足元が下端付近に整えます。色相も自動で取得します。

5仕様

倍率は1より大きいと強化、小さいと弱化です(被ダメージとクールタイムは小さいほど有利)。 射程と弾速は技そのものの数字に掛けて焼き込みます。
すでにいるモンスターと同じものを選ぶか、「自分で決める」で組み合わせられます。 倍率は1より大きいと強化、小さいと弱化です(クールタイムと消費ガッツと被ダメージは小さいほど有利)。
色スキンはオーラの色以外の5色を自動でつけます。塗り替える部分(主役の色)も アイコン画像から自動で決めるので、入力するところはありません。
