  荒野行動自体がスマホで60fps級なので、重くて動かない画は「荒野行動超え」にならない。

## 各担当からの申し送り(消さない)

**⚠️ サブエージェント側に `Agent` ツールが無く、「厳しい批評担当を別に立てる」工程が
どの担当でも実行できていない。** 各担当の点数はすべて自己採点。**批評は統合後に本体側でやる。**

### 水(完了)
- **海面の高さの決め方を1点だけ変えた。** `world.js` の `isInSea` は
  `x < seaEdgeX(y)` の2D判定で高さを一切見ない(確認済み)。一方で旧`levelAt`は沖の地形だけを
  見ていたため海面が浜より低く落ち、「海の判定なのに乾いた砂が見えている」状態だった。
  波打ち際の地面を基準にして上下限を付けた = **見た目と2D判定のズレが減る方向の変更**。
  3D側の水面高さをゲーム側が読み返している箇所は無い(確認済み)。**実機で確認してもらうこと。**
- 直したバグ2件: `resetDynamicLists`が水面シェーダーの登録を捨てて2マップ目から波が止まっていた /
  手組み円盤の三角形の巻きが逆で溶岩と濡れた砂が裏面カリングで消えていた。
- 未実装: 浅瀬のコースティクス、浜の「濡れた砂の帯」(地面側の担当)。

### 空・遠景(完了)
- **雲が動かない。** `real3d.js` に空用の毎フレームのフックが無いため。空側に1行足せば流せる。
  → **本体側で対応する**(`render()` の中で `sky` のuniformに時間を渡す)。
- **荒野(wild)のテーマ色が暗すぎる**(`skyTop 0x1b2740`/`ridgeRock 0x4a5260`)。
  色を決め打ちしない方針では限界。→ **`data.js` のテーマ調整は本体側の担当**なのでそこで見る。
- 遠景の岩肌テクスチャが一周に5〜9回繰り返しており、うっすら見える。
- パレパレは森の山(props側)が画面を塞いで空がほとんど見えず、検証できていない。

### 統括(ライティング・色調)で決めたこと
- **雲を風で流すフックを入れた**(空の申し送り①に対応)。速さは実測で決定。
  最初の値(0.0135/秒)は20秒で雲の柄が入れ替わり早送りに見えたので1/10にした。
- **`data.js` の `REAL3D_THEMES` を4マップ調整**(kaurea と toble は良かったので触らない):
  - `wild` 全体が暗すぎて地面の作り込みが沈んでいた → 「薄暗い」性格は残して明度を上げた
  - `palepale` **空まで緑で画面全体が緑一色のスープだった** → 空は熱帯の青・霞は白い靄にし、
    緑は地面だけが持つように。`steep`/`gravel` を茶色にして土の色を出す
    (地面担当が「土色が欲しい」と言っていた件はこれで対応)
  - `papas` 空も地面も白くて溶けていた → 天頂を濃い青にして「青い空 対 白い雪」の対比を作る
  - `mandy` 砂と空が同じ金色 → 天頂だけ青を強くした
- **撮影ハーネスを修正**: マップごとにページを作り直す。1ページ使い回しだと
  WebGLコンテキストが積み上がって上限に当たり、植生でシーンが重くなってから途中で止まった。

## 触ってはいけない約束(壊すと実機で事故る)

- 2Dの `project()` と3Dカメラの一致(FOV_V=64° / camPos / yaw,pitch)
- 地形の高さは `data.js` の `real3dHeightAt()`。当たり判定と同じ関数を使う
- 障害物の寸法は `data.js` の `OBST_SHAPES` が正。3Dモデルを変えたら表も直す
  (render.js の2Dくり抜きが同じ表を読む)
- `window.__aramonReal3D` の API 形(setActive/render/resize/stats/obstacleCullDist)
- 最大傾斜は0.3程度まで(超えると坂を登れなくなる。`CLIMB_TOLERANCE`)
