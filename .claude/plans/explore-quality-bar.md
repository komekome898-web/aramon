# 探検モード 品質基準(批評家が使う採点表)

目標は「モンスターハンター最新作 / APEX Legends と並べて遜色ない、スマホで荒野行動より良く見える探検体験」。
実ゲーム画像は取得できない環境なので、批評家は各作品の**実際の画面を記憶から具体的に思い浮かべ**、
撮影画像と「ブラインドで並べたらどちらが良く見えるか」を項目ごとに判定する。
10点満点。**7点未満が1つでもあれば不合格**。総合(E10)は8点以上。

| # | 項目 | 見るところ(ここが無ければ減点) |
|---|---|---|
| E1 | フィールドの広さと入り組み | 見渡して「行きたい場所」が複数ある。峡谷・尾根道・路地で一本道でない。地域ごとに景色がはっきり違う。遠景にランドマーク |
| E2 | 地域の美しさ | 空・霞・地面・植生・光の色が地域ごとに設計されている(モンハンの各地域級)。単色の地面・何もない平地が続かない |
| E3 | 野生モンスターとの遭遇 | 群れがうろつき、気づくと「!」、追ってくる、縄張りに戻る。生き物らしい。倒すと素材が弾ける |
| E4 | ボス戦 | 登場の見せ場(名前の札・咆哮)、専用HPバー、予告→大技、怒り、弱点・部位破壊、逃走。倒した瞬間の報酬演出 |
| E5 | ルート(APEX) | 補給箱が開く演出、レア度の色(白青紫金)と光の柱、拾った物の通知。一目で価値が分かる |
| E6 | 狙撃銃とスコープ | 構えたときの倍率ズーム、スコープの画(周辺の暗さ・十字線・距離)、揺れと息止め、弾の落下、命中・クリティカルの手応え |
| E7 | HUD | 方位バー、目標表示、ミニマップ、残り時間/力尽き回数。情報が多くても読める。縦持ち3サイズで崩れない |
| E8 | 装備と工房 | 素材→装備の流れが分かる。装備が格好良く並ぶ。作ったときの演出。探検で強くなった実感 |
| E9 | 始まりと終わり | 出発(ベースキャンプ)と帰還・リザルト(持ち帰った物が並ぶ)。力尽き・時間切れの扱いが明快 |
| E10 | 総合の説得力 | ブラインドで「スマホの本格ハンティング×BRゲームの画面だ」と言えるか。作りかけに見えたら0点 |

## 動作条件(外したら何点でも不合格)

- iPhoneのブラウザ(PWA)で動く重さ。描画が増えたら `--bench` 等で実測する。
- 既存モード(シングル/チーム戦/レイド/訓練場)の挙動を変えない。分岐は `game.explore` 1つ。
- CLAUDE.md の画面の3原則(R1〜R3)・`--vh`・スクロールロック除外3か所・メディアクエリ禁止を守る。
- 画像・音のファイルは原則増やさない(テクスチャ・音は手続き生成)。
